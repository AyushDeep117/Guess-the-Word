# Guess The Word

A web-based 5-letter word guessing game built as part of the OpenText project assignment.

## Current Status

Project setup completed.

## Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Planned Features

- User registration and login
- Player and Admin roles
- Word guessing game
- Maximum 5 guesses per game
- Maximum 3 games per player per day
- Wordle-style letter evaluation
- Game history
- Admin reports
- Unit tests
